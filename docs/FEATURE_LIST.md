# FraudRoko - Complete Feature List

Version: 1.0

Status: Planning

---

# Project Goal

FraudRoko is an Android Cyber Safety Assistant designed to help users protect their smartphones from cyber threats, scams, unsafe settings, fake apps, and online fraud.

The application focuses on education, prevention, and security guidance rather than acting as a traditional antivirus.

---

# V1 Core Features

## 1. Phone Security Check

One-click phone security scan.

Checks:

- Android Version
- Security Patch
- Screen Lock
- Developer Options
- USB Debugging
- Play Protect
- Device Encryption
- Root Detection
- Unknown Sources
- Device Health

Result:

- Security Score
- Risk Level
- Fix Now Suggestions

---

## 2. Privacy Check

Analyze privacy-related settings.

Checks:

- Camera Access
- Microphone Access
- Location Access
- Contacts Access
- SMS Access
- Notification Access
- Accessibility Services
- Overlay Permission

---

## 3. App Security Check

Analyze installed applications.

Checks:

- Dangerous Permissions
- Accessibility Apps
- Device Admin Apps
- Overlay Apps
- Fake Banking Apps
- Fake UPI Apps
- Fake Government Apps
- Duplicate Apps
- Suspicious Package Names

---

## 4. Link Checker

Check whether a URL appears safe or suspicious.

Features:

- Safe
- Suspicious
- Dangerous
- Explain the reason

---

## 5. QR Code Scanner

Scan QR Codes.

Detect

- Phishing Links
- Fake Payment QR
- Suspicious Websites

---

## 6. APK Scanner

User-selected APK analysis.

Checks:

- APK Information

# Features Removed

The following features will NOT be implemented because they violate Android or Google Play policies:

- Full Antivirus
- Automatic Malware Removal
- Reading Private WhatsApp Data
- Reading SMS Without Permission
- Reading Contacts Without Permission
- Deep System Scanning
- Hidden Background Surveillance

# Final Principle

Every feature must:

- Respect user privacy.
- Follow Android policies.
- Follow Google Play policies.
- Provide clear guidance to the user.
- Build trust instead of fear.
